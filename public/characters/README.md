# 3D Animated Doraemon Mascot Asset Directory

Drop custom 3D Doraemon character assets here to replace or enhance the default procedural 3D SVG mascot:

### Supported File Formats:
- **`doraemon.png`** / **`doraemon.gif`** / **`doraemon.glb`**

When a PNG/GIF asset is placed here (`doraemon.png` or `doraemon.gif`), APSB Nexus automatically loads it with full 3D tilt, floating physics, signature cyan/blue aura, and speech greeting animations!
